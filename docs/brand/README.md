# Grove Park Collective — logo files

Traced to vector (SVG) from the black-and-white logo concepts, so they scale to any size and
can be recolored by changing the `fill` values in the file.

| File | Use |
|---|---|
| `logo-a-*.svg` | Portrait logo with rules above and below |
| `logo-b-*.svg` | Portrait logo with rules down both sides |
| `lockup-*.svg` | Horizontal logo (tree + GROVE PARK / COLLECTIVE) for headers and letterheads |
| `logo-a-duo.png`, `logo-b-duo.png` | High-resolution PNGs on white, for documents and social posts |

Colorways: `duo` (grove green + clay — used on the site), `green`, `clay`, `black`, `white` (for dark backgrounds).

Brand colors: grove green `#2F4A3A`, clay `#B5653D`, limestone background `#F6F3EE`.

The files the website actually uses are in `public/assets/img/brand/` (`logo.svg`, `lockup.svg`,
`mark.svg`, `favicon.svg`, `apple-touch-icon.png`, `email-logo.png`). To try a different colorway
on the site, replace those with the matching files from this folder (the header uses a lighter-weight
copy of the lockup; any lockup file here works too).
